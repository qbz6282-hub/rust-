# rust人工智能應用工程
惟第一版是一位高職二年級資訊科學生無人工智慧模型幫助所製
其依賴庫共有reqwest、serde、serde_json、tokio，且版本皆為最新
後續會有應用工程方面的更新。
具體更新方向是增加"代碼編寫"工具，但讓模型在主要環境直接運行代碼編寫工具就有權限過大而導致電腦內的不應變動資料被修改，因此我使用WSL來連接podman這個免費沙箱環境，podman根據自身系統下載，我是windows/x86，故選用相關安裝包，但注意我是用"MSI"

與main.rs相關資訊
main.rs檔案已被運行過，然本人本地端模型皆未訓練過工具調用能力，故往後將尋找合適模型進行測試，具體情況便是可編譯與運行，而openrouter平台上的免費模型額度似乎都化為滾木，回傳400、429乃是常態
